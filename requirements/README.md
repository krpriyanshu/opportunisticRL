# Requirements

`pyproject.toml` at the repository root is the canonical dependency specification: `pip install -e .`, or with the `dev`, `rl` and `viz` extras as needed.

This directory is reserved for **pinned, reproducibility-grade lock files** — for example `requirements/rl-lock.txt`, generated by `pip freeze` at the point a reported experiment was run, alongside that experiment's recorded revision hash.

It is currently empty, and that is a gap rather than a deferral. The experiments described in [docs/evaluation.md](../docs/evaluation.md) have been run, so there is now something to pin against, and the absence of a lock file is one component of the provenance problem documented in [docs/evaluation.md §2](../docs/evaluation.md#2-provenance-and-status-of-the-evidence): the reported results cannot be tied either to a revision or to a dependency set. A lock file should be generated as part of regenerating those results.
